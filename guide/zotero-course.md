# 🎓 Вводный курс: Zotero для академического письма

**Цель курса:** Научиться собирать, организовывать и цитировать источники для научных статей. Связь с Obsidian — экспорт literature notes.

**Время:** 40 минут (6 уроков по 5–10 минут)  
**Что нужно:** Zotero установлен, браузерный коннектор установлен

---

## Урок 1. Первая статья в библиотеку (5 минут)

### Цель
Научиться сохранять источники из интернета напрямую в Zotero.

### Теория
Zotero работает в паре: программа на компьютере + расширение в браузере. Когда ты на странице со статьей (Google Scholar, CyberLeninka, издательский сайт), коннектор «читает» метаданные и сохраняет всё автоматически.

### Практика — шаги

**Шаг 1.** Открой любую научную статью в браузере. Примеры работают идеально:
- https://scholar.google.com
- https://cyberleninka.ru
- Сайт журнала (vestnik.rudn.ru и подобные)

**Шаг 2.** Посмотри на иконку Zotero в адресной строке браузера (справа, выглядит как буква «Z» или иконка документа).

**Шаг 3.** Нажми на иконку. Через 1–2 секунды появится всплывающее окно: «Сохранение статьи...».

**Шаг 4.** Открой Zotero на компьютере. В верхней центральной панели появилась новая запись с:
- Названием статьи
- Авторами
- Годом
- DOI (если есть)
- PDF (если доступен — прикрепится автоматически)

### Задание
Сохрани 3 статьи из Google Scholar по запросу «медиасистема конфликт».

### Чеклист
- [ ] Расширение Zotero видно в браузере
- [ ] Нажал на иконку — статья сохранилась
- [ ] В Zotero появилась запись с метаданными
- [ ] Сохранено 3 статьи из Google Scholar

## Урок 2. Коллекции — папки для проектов (5 минут)

### Цель
Разложить источники по темам, чтобы не искать потом в 500 записях.

### Теория
Коллекция = папка. Источник может быть одновременно в нескольких коллекциях (копии не дублируются, это «ссылки»). Левая панель — дерево коллекций.

### Практика — шаги

**Шаг 1.** В левой панели Zotero правая кнопка мыши → «Новая коллекция...»

**Шаг 2.** Назови: `Медиасистема и СВО`

**Шаг 3.** Создай ещё две:
- `Аналитические системы`
- `Методология`

**Шаг 4.** Перетащи одну из сохранённых статей (Урок 1) в коллекцию «Медиасистема и СВО». Смотри: статья осталась и в общей библиотеке, и в папке — это нормально.

### Продвинутый приём: вложенные коллекции
Правая кнопка на коллекции → «Новая подколлекция...»

Структура для твоего профиля:
```
Библиотека
├── Медиасистема и СВО
│   ├── Источники СВО
│   └── OSINT в конфликтах
├── Аналитические системы
│   ├── Реестры инструментов
│   └── Сравнительные исследования
├── Методология
│   ├── Качественные методы
│   └── Метрики медиасистем
└── Литература по медиа
    ├── Теория медиасистем
    └── Военная журналистика
```

### Задание
Создай коллекцию с тремя подколлекциями и распредели 5 сохранённых статей.

### Чеклист
- [ ] Создано минимум 3 коллекции
- [ ] Статьи распределены по коллекциям
- [ ] Есть хотя бы одна подколлекция
- [ ] В коллекции «Медиасистема и СВО» минимум 2 статьи

## Урок 3. Теги и заметки — мозговой штурм (10 минут)

### Цель
Научиться помечать источники, чтобы потом найти их за 3 секунды.

### Часть А. Теги

**Теория.** Тег = метка. У одного источника может быть много тегов. Ищешь по тегу — Zotero показывает всё сразу.

**Шаги:**
1. Выдели статью в центральной панели
2. Справа внизу — поле «Теги»
3. Кликни, введи: `методология`
4. Нажми Enter
5. Добавь ещё: `цитировать`, `OSINT`

**Система тегов для твоих проектов:**

| Тег | Когда использовать |
|-----|-------------------|
| `методология` | Статья описывает метод — можно повторить |
| `цитировать` | Ключевой тезис — нужен в статье |
| `проверить` | Что-то подозрительно — перепроверить факт |
| `OSINT` | Работа с открытыми данными |
| `связь-медиа-война` | Прямая связь темы: медиасистема и конфликт |
| `альтернатива` | Статья с другой точкой зрения |
| `важное` | Must-read, фундаментальный текст |

**Поиск по тегу:**
- Внизу левой панели кликни «Теги»
- Появится список всех тегов
- Кликни на тег — отфильтрует источники

### Часть Б. Заметки

**Теория.** Заметка в Zotero = твоя интерпретация источника. Не аннотация извне, а твои мысли.

**Шаги:**
1. Открой статью (двойной клик или выдели → правая панель)
2. Вкладка «Заметки» → «Добавить»
3. Напиши по шаблону:

```
Ключевой тезис: ...
Метод: ...
Данные: ...
Критика: ...
Где применимо в моей статье: ...
Цитата для использования: "..."
```

### Задание
Добавь теги к 5 статьям. Минимум 2 тега на статью. Напиши заметку к одной статье по шаблону.

### Чеклист
- [ ] У 5 статей есть теги
- [ ] Есть тег `методология` или `цитировать`
- [ ] Написана одна заметка по шаблону
- [ ] Проверил поиск по тегу — работает

## Урок 4. Цитирование в ГОСТ (5 минут)

### Цель
Копировать цитаты в правильном формате без ручной правки.

### Теория
Zotero хранит стиль цитирования отдельно от данных. Меняешь стиль — все цитаты перестраиваются автоматически.

### Практика — шаги

**Шаг 1.** Настрой стиль
- Правка → Настройки → Экспорт → Стиль цитирования по умолчанию
- Выбери: «ГОСТ Р 7.0.5-2008» или «Russian GOST R 7.0.11-2011»
- Если нет — кнопка «Управление стилями» → найди «GOST» → установи

**Шаг 2.** Быстрое цитирование
- Выдели статью в Zotero
- Нажми `Ctrl+Shift+C` (или `Cmd+Shift+C` на Mac)
- Открой документ / Obsidian / Word
- Вставь (`Ctrl+V`) — цитата в формате ГОСТ

**Пример результата:**
```
Водопетов С.В. Медиасистема как фактор информационного сопровождения вооружённых конфликтов // Вестник РУДН. — 2025. — № 3. — С. 45–58.
```

**Шаг 3.** Библиографический список
- Выдели несколько статей (Ctrl+клик)
- Правая кнопка → «Создать библиографию по выделенным объектам»
- Выбери формат: «Список литературы»
- Скопируй и вставь в конец статьи

### Задание
Скопируй 3 цитаты в формате ГОСТ и вставь в тестовый документ.

### Чеклист
- [ ] Установлен стиль ГОСТ
- [ ] Ctrl+Shift+C копирует цитату
- [ ] Цитата выглядит как в ГОСТ (фамилия, инициалы, название, журнал, год)
- [ ] Создан библиографический список из 3+ источников

## Урок 5. Связь Zotero → Obsidian (10 минут)

### Цель
Автоматически перенести источники из Zotero в Obsidian vault как literature notes.

### Теория
Zotero хранит данные в SQLite базе. Скрипт `zotero-export.py` читает эту базу и создаёт markdown-файлы в Obsidian.

### Практика — шаги

**Шаг 1.** Найди путь к Zotero базе
- Обычно: `~/Zotero/zotero.sqlite` (Mac/Linux)
- Или: `C:\Users\ИМЯ\Zotero\zotero.sqlite` (Windows)

**Шаг 2.** Отредактируй скрипт (если путь отличается)
```bash
cd ~/ObsidianVault
nano scripts/zotero-export.py
# Найди строку ZOTERO_DB = и укажи правильный путь
```

**Шаг 3.** Запусти экспорт
```bash
cd ~/ObsidianVault
python3 scripts/zotero-export.py
```

**Шаг 4.** Проверь результат
- В Obsidian открой папку `01-sources/`
- Увидишь файлы вида `source-ivanov-2024.md`
- Открой — там структура: аннотация, тезисы, цитаты, связи

**Шаг 5.** Свяжи с статьёй
- В Obsidian открой черновик статьи
- Напиши: `[[source-ivanov-2024]]` — Obsidian подскажет автодополнением
- Кликни на ссылку — перейдёшь к literature note

### Что происходит дальше
1. Работаешь в Zotero (собираешь источники, пишешь заметки)
2. Раз в неделю запускаешь `zotero-export.py`
3. Новые источники появляются в Obsidian
4. Связываешь их со статьями через `[[ссылки]]`

### Задание
Экспортируй минимум 5 источников. Свяжи 3 из них со статьёй в `02-articles/01-drafts/`.

### Чеклист
- [ ] Скрипт zotero-export.py запущен
- [ ] В `01-sources/` появились .md файлы
- [ ] Файлы содержат метаданные (автор, год, DOI)
- [ ] В статье есть `[[source-...]]` ссылки на 3 источника
- [ ] Ссылки работают (клик → переход)

## 🆘 Типичные проблемы

**Проблема:** Иконка Zotero в браузере не появляется  
**Решение:** Убедись, что Zotero программа запущена. Перезапусти браузер.

**Проблема:** Статья сохранилась без PDF  
**Решение:** PDF был за paywall. Скачай вручную и перетащи в запись Zotero.

**Проблема:** Экспорт в Obsidian не работает  
**Решение:** Проверь путь к `zotero.sqlite` в скрипте. Убедись, что Zotero не запущен (база locked).

**Проблема:** Ссылки `[[source-...]]` в Obsidian не работают  
**Решение:** Включи Wiki-ссылки: Obsidian → Настройки → Файлы и ссылки → Wiki-ссылки.
