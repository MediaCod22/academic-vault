# Серверные аналоги Obsidian + Zotero

## Что уже развёрнуто

| Компонент | Серверный аналог | Статус |
|-----------|-----------------|--------|
| Obsidian (markdown + структура) | **HedgeDoc** | ✅ На порту 3006 |
| Git backup | **Git bare repo** | ✅ На сервере |

## Чего не хватает

### 1. Полноценный серверный аналог Obsidian

**HedgeDoc** — это редактор, но не хранилище с графом связей. Есть более мощные варианты:

| Инструмент | Что умеет | Сложность деплоя | Подходит? |
|------------|-----------|-----------------|-----------|
| **Wiki.js** | Markdown, папки, поиск, роли пользователей, история | Docker, 5 минут | ⭐⭐⭐⭐⭐ |
| **BookStack** | Структура "книги→полки→главы", WYSIWYG, комментарии | Docker, 5 минут | ⭐⭐⭐⭐ |
| **Outline** | Очень красивый, Slack-like, markdown | Docker + OIDC/Slack auth, 20 мин | ⭐⭐⭐ |
| **Trilium Notes** | Иерархия, шифрование, markdown, self-hosted | Docker, 5 минут | ⭐⭐⭐ |

**Мой выбор для тебя: Wiki.js**
- Чистый markdown (как Obsidian)
- Структура папок
- Пользователи и роли (ты и редактор)
- Встроенный поиск
- Лёгкий Docker
- Экспорт в markdown

### 2. Серверный аналог Zotero

| Инструмент | Что умеет | Оценка |
|-----------|-----------|--------|
| **Zotero Web** | Синхронизация, но основной функционал — в десктопе | Ограничено |
| **BibSonomy** | Веб-сервис библиографии, но устаревший | ❌ |
| **JabRef + Web** | Нет серверной версии с UI | ❌ |
| **Zotero API + скрипт** | Самописная обёртка | Сложно |

**Проблема:** полноценного серверного Zotero-аналога с UI нет. Лучшее решение — продолжать использовать Zotero десктопный, а на сервере хранить только экспортированные literature notes.

## Предложение: дополнить текущее решение Wiki.js

Разворачиваю Wiki.js рядом с HedgeDoc:

```
Порт 3006: HedgeDoc — быстрое редактирование (уже есть)
Порт 3007: Wiki.js — структурированное хранилище статей
```

**Wiki.js даёт:**
- Структуру папок как в Obsidian
- Markdown + WYSIWYG редактор
- Пользователи: Владелец (admin), Редактор (editor)
- История изменений (встроенная)
- Экспорт в markdown → Git
- Поиск по всем статьям
- Комментарии к страницам

**НЕ даёт (в отличие от Obsidian):**
- Граф связей (graph view)
- Wiki-ссылки `[[статья]]` (есть внутренние ссылки, но не такие)
- Плагины

## Два варианта дальнейшего развития

### Вариант А: Минимум (текущее решение)
- HedgeDoc (3006) — для быстрой правки
- GitHub + Git bare — для хранения
- Zotero — локально на десктопе
- Obsidian — локально на десктопе

**Плюсы:** уже работает, ничего не надо добавлять
**Минусы:** редактор работает в браузере без структуры, нет серверного хранилища

### Вариант Б: Wiki.js + текущее (расширенное)
- **Wiki.js (3007)** — серверная структурированная wiki для статей
- **HedgeDoc (3006)** — для быстрых черновиков
- **GitHub + Git bare** — backup всего
- **Zotero** — локально (источники)

**Плюсы:** редактор работает в структурированной системе, есть версионирование, поиск
**Минусы:** ещё один сервис, Obsidian по-прежнему локально

## Мой совет

Если редактору нужна **структура** (папки, организация, поиск) — разворачиваем Wiki.js.
Если редактору достаточно **браузера + Git** — оставляем текущее решение.
